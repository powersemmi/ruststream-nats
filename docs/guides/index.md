# Guides

`ruststream-nats` is the NATS broker for [RustStream](https://powersemmi.github.io/ruststream/latest/),
built on [async-nats](https://docs.rs/async-nats). It serves Core NATS subjects and JetStream
streams. The guides take a NATS service from installation to production.
