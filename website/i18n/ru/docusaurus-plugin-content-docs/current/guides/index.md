# Руководства

Крейт `ruststream-nats` реализует брокер NATS для [RustStream](https://powersemmi.github.io/ruststream/latest/ru/).
Он построен на клиенте [async-nats](https://docs.rs/async-nats). Крейт работает с субъектами Core NATS
и стримами JetStream. Руководства проводят сервис на NATS от установки до промышленной эксплуатации.
