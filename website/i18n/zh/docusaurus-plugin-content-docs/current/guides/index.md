# 指南

`ruststream-nats` 是 [RustStream](https://powersemmi.github.io/ruststream/latest/zh/) 的 NATS Broker，
基于 [async-nats](https://docs.rs/async-nats) 构建，支持 Core NATS subject 和 JetStream 流。
这些指南带你把一个 NATS 服务从安装一路推进到生产环境。
